# 🚂

One Emoji, One Dream Vacation — a [make.fun](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) entry.

The entry is a single emoji: 🚂 (U+1F682, railway car). The field is full of
static postcards — desert islands, Mount Fuji, sunrises, night skies. This one
is the journey itself: a sleeper train crossing borders while you sleep, the
dining car at dusk, the window sliding past a new country every morning.
A dream vacation that moves.

## How it works

`main.ts` writes exactly one emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`). Node standard library only — no
dependencies, no network, no randomness. The output is byte-identical on
every run.
